## Giới thiệu

**《Series đọc source code Java không thể bỏ qua》** là một ebook nội bộ trong [Knowledge Planet](../about-the-author/zhishixingqiu-two-years.md) của tôi, hiện đã tổng hợp source code của Dubbo 2.6.x, Netty 4.x, Spring Boot 2.1 và các framework/middleware khác. Sau này sẽ tiếp tục tổng hợp thêm nhiều source code chất lượng đáng đọc và không ngừng hoàn thiện.

Cấu trúc rõ ràng, nội dung chi tiết, rất phù hợp với những bạn muốn tìm hiểu sâu về source code của framework/middleware.
