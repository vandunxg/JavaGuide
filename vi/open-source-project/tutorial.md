Trang này chỉ tuyển chọn các tài liệu phù hợp để học có hệ thống hoặc tra cứu theo chủ đề. Các hệ thống nghiệp vụ hoàn chỉnh nằm trong [dự án thực chiến](./practical-project.md), còn framework và middleware nằm trong [framework và hạ tầng](./system-design.md).

## Java Basics và nâng cao

- [JavaGuide](https://github.com/Snailclimb/JavaGuide "JavaGuide"): guide học tập bao quát kiến thức Java core, database, system design, distributed system, high performance và chuẩn bị phỏng vấn.
- [toBeBetterJavaer](https://github.com/itwanger/toBeBetterJavaer): guide học Java dễ hiểu, hài hước, bao quát các điểm kiến thức như Java Basics, Java Collection Framework, Java concurrency, JVM và Java enterprise development (Git, SSM, Spring Boot).
- [advanced-java](https://github.com/doocs/advanced-java "advanced-java"): kiến thức nâng cao dành cho Java engineer, bao quát high concurrency, distributed system, high availability, microservice và xử lý dữ liệu quy mô lớn.
- [bestJavaer](https://github.com/crisxuan/bestJavaer): tutorial theo chủ đề Java Basics, JVM, concurrency, database và middleware.
- [java-design-patterns](https://github.com/iluwatar/java-design-patterns "java-design-patterns"): design patterns được triển khai bằng Java.

## Ví dụ code Spring

- [Building an Application with Spring Boot](https://github.com/spring-guides/gs-spring-boot): ví dụ nhập môn chính thức của Spring, bắt đầu từ cấu hình tối thiểu để xây dựng một ứng dụng Spring Boot có thể chạy được.
- [Building REST services with Spring](https://github.com/spring-guides/tut-rest): tutorial REST chính thức của Spring, bao quát modeling resource, HTTP API và hypermedia.
- [Baeldung Tutorials](https://github.com/eugenp/tutorials): repository code ví dụ Java và Spring đi kèm các bài viết của Baeldung. Repository có quy mô rất lớn, phù hợp hơn để tra cứu ví dụ theo module, không nên đọc từ đầu đến cuối.

## Kiến thức máy tính cơ bản

- [cs-self-learning](https://github.com/PKUFlyingPig/cs-self-learning): guide tự học computer science, tổng hợp các khóa học computer science chất lượng cao của nhiều trường đại học danh tiếng ở châu Âu và Hoa Kỳ.

## Thuật toán và data structure

- [The Algorithms - Java](https://github.com/TheAlgorithms/Java): triển khai các thuật toán và data structure thường gặp bằng Java, phù hợp để đối chiếu code và hiểu tư duy, cũng có thể dùng làm tham khảo cho lời giải bài tập. Trước khi sử dụng, cần chú ý phần mô tả complexity và độ bao phủ của test ở từng implementation, không đưa thẳng code ví dụ vào production.

## Sách open source

- [Nguyên lý triết học của high concurrency](https://github.com/johnlui/PPHC): mục tiêu của cuốn sách là thảo luận, trong phạm vi nhận thức hữu hạn của tác giả, về một nguyên lý triết học ẩn sau vấn đề high concurrency: tìm ra single point rồi phân tách nó.
- [Bản tiếng Trung của DDIA (Designing Data-Intensive Application)](https://github.com/Vonng/ddia): bản dịch tiếng Trung của Designing Data-Intensive Application (DDIA).
- [Kiến trúc Phượng Hoàng](https://github.com/fenixsoft/awesome-fenix): thảo luận cách xây dựng một distributed system lớn đáng tin cậy.
