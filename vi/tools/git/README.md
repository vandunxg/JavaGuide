Git là công cụ nền tảng mà developer bắt buộc phải nắm. Khi học Git, bạn không nên chỉ học thuộc command, mà còn cần hiểu version control model, commit history, branch collaboration và conflict handling để không bị lúng túng khi team collaboration hoặc đóng góp cho open source.

## Dành cho ai

- Backend beginner mới bắt đầu làm quen với Git và GitHub.
- Developer thường xuyên sử dụng Git command nhưng chưa hiểu rõ workspace, staging area, branch và remote repository.
- Độc giả chuẩn bị phỏng vấn, cần trình bày rõ các câu hỏi thường gặp về Git.
- Độc giả muốn nâng cao GitHub profile, project showcase và hiệu quả open source collaboration.

## Trọng tâm học

- Git là distributed version control system, cốt lõi là ghi lại code snapshot và commit history.
- Workspace, staging area, local repository và remote repository lần lượt tương ứng với các trạng thái code ở những giai đoạn khác nhau.
- Branch cho phép nhiều người phát triển song song, còn merge và conflict handling là các scenario thường gặp trong team collaboration.
- Cần kết hợp Git command với workflow thực tế để hiểu, chẳng hạn như clone, add, commit, branch, merge, pull và push.
- GitHub có thể dùng cho code hosting, project showcase, open source collaboration, code search, Actions automation và xây dựng ảnh hưởng cá nhân.
