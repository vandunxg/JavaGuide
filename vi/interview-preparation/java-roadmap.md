::: tip Lưu ý quan trọng

Lộ trình học này được **chỉnh sửa có hệ thống hằng năm**, đồng bộ nghiêm ngặt với hệ sinh thái công nghệ Java và những động thái mới nhất của thị trường tuyển dụng, **đảm bảo tính cập nhật và định hướng tương lai của nội dung**.

:::

Sau một tháng dày công hoàn thiện, tác giả đã dựa trên những yêu cầu mới nhất trong tuyển dụng vị trí phát triển Java backend hiện nay để nâng cấp toàn diện lộ trình học hiện có. Lần nâng cấp này bao gồm các khía cạnh như bổ sung và loại bỏ tech stack, tối ưu hóa lộ trình học, cập nhật tài nguyên học tập đi kèm, nỗ lực xây dựng một hệ thống kiến thức phù hợp hơn với đường cong phát triển của Java developer.

Tổng quan bản sáng:

![Tổng quan PDF lộ trình học Java - bản sáng](https://oss.javaguide.cn/github/javaguide/interview-preparation/java-road-map-pdf.png)

Tổng quan bản tối:

![Tổng quan PDF lộ trình học Java - bản tối](https://oss.javaguide.cn/github/javaguide/interview-preparation/java-road-map-pdf-dark.png)

Đây có thể là lộ trình học Java backend được đầu tư công phu và toàn diện nhất mà bạn từng thấy. Lộ trình học này có tổng cộng **hơn 40.000** chữ, nhưng bạn hoàn toàn không cần lo nội dung quá nhiều và không học hết được. Dựa trên độ khó học tập, tôi sẽ phân chia nội dung bắt buộc phải học nếu muốn tìm việc ở công ty nhỏ và lộ trình học phù hợp để từng bước nâng cao năng lực phát triển Java backend.

![Sơ đồ lộ trình học Java](https://oss.javaguide.cn/github/javaguide/interview-preparation/java-road-map.png)

Với người mới bắt đầu, bạn có thể học tập có hệ thống theo lộ trình và tài liệu được đề xuất trong bài viết này; với developer có kinh nghiệm, bạn có thể dựa trên bài viết này để học chuyên sâu hơn về phát triển Java backend và nâng cao năng lực cạnh tranh cá nhân.

Trong quá trình xem lộ trình học này, bạn nên kết hợp với [Tổng hợp trọng tâm phỏng vấn Java (quan trọng)](https://javaguide.cn/interview-preparation/key-points-of-interview.html) để việc học có mục tiêu rõ ràng hơn.

Vì lộ trình học này có quá nhiều nội dung nên tôi đã biên soạn thành phiên bản PDF (tổng cộng **55** trang) để mọi người dễ đọc. PDF này có hai phiên bản đọc ban đêm và ban ngày, đáp ứng các nhu cầu khác nhau.
